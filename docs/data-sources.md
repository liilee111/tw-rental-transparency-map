## 3. 實價登錄租賃資料

| 項目 | 內容 |
|---|---|
| 提供者 | 內政部地政司 |
| 網址 | 不動產交易實價查詢服務網 https://lvr.land.moi.gov.tw/ （開放資料下載頁網址待確認） |
| 租金類型 | **成交租金**（實際簽約租金） |
| 格式 | CSV／XML，依縣市分檔；租賃案件為獨立檔案（檔名規則待確認） |
| 授權 | 政府資料開放授權條款－第 1 版（待確認）；此授權與 CC BY 4.0 相容，需標示出處 |
| 更新頻率 | 每月 1、11、21 日發布（待確認） |
| 涵蓋範圍 | 全國各縣市 |
| 使用階段 | MVP 1（縣市統計）、MVP 2（行政區統計） |

### 3.1 預計使用欄位

以下欄位名稱需以實際下載的檔案為準（待確認）：

| 欄位 | 用途 |
|---|---|
| 鄉鎮市區 | 行政區統計（MVP 2） |
| 交易標的 | 排除只租車位、只租土地的案件 |
| 土地位置建物門牌 | 房屋 1 的地址對應；MVP 1 不使用 |
| 租賃年月日 | 統計期間（民國年格式，需轉換） |
| 建物型態、主要用途 | 排除非住宅用途 |
| 出租型態 | 區分套房／雅房／整層（待確認欄位值） |
| 建物現況格局（房／廳／衛） | 輔助判斷房屋類型 |
| 建物總面積（平方公尺） | 每坪租金 |
| 總額元 | 月租金 |
| 車位總額元 | 判斷租金是否含車位 |
| 有無附傢俱、附屬設備 | US-13 篩選（MVP 3） |
| 備註 | 排除特殊關係交易（如親友間租賃） |
| 編號 | 去除重複、追蹤資料修正 |

### 3.2 已知限制

> [!IMPORTANT]
> **實價登錄的租賃資料不是全部的租屋市場。** 依現行法規，主要是透過不動產經紀業或租賃住宅服務業（代管、包租）成交的案件才有申報義務；房東與房客直接簽約的案件通常不需申報。

這代表：

- **樣本偏向特定物件**：可能偏向透過仲介、代管的物件，低估或高估整體行情都有可能，方向不確定。
- **部分縣市樣本很少**：非六都地區的樣本數可能不足以產生統計（見 [methodology.md §5](methodology.md#5-最低樣本數)）。
- **費用內容不明**：租金是否含管理費、水電，目前欄位未見明確標示（待確認）。依 US-04，無法確定時應顯示「未提供」。
- **申報時間落差**：簽約後一段時間才申報、再等下一次發布，最新幾週的資料一定不完整。
- **地址可能為區間**：租賃案件的門牌可能以區間呈現（例如「1～30 號」）（待確認），會影響房屋 1 的地址對應。

介面上必須說明這些限制（US-06）。

## 4. 開放台灣民間租屋資料

| 項目 | 內容 |
|---|---|
| 提供者 | g0v 社群專案（維護者待確認） |
| 網址 | https://rentalhouse.g0v.ddio.io/ |
| 租金類型 | **刊登租金**（廣告開價，不是成交價） |
| 原始資料 | 蒐集自民間租屋平台的刊登資訊（來源平台待確認） |
| 格式 | 待確認（CSV／API） |
| 授權 | **待確認**。資料源自商業平台，即使專案本身採開放授權，原始刊登內容能否再發布仍需確認 |
| 更新頻率 | 待確認；需確認專案是否仍在維護 |
| 涵蓋範圍 | 待確認 |
| 使用階段 | 待決定 |

### 4.1 為什麼仍考慮使用

實價登錄樣本偏向仲介／代管物件，刊登資料可以補上「房東直租」的市場樣貌，而且數量通常多很多。

### 4.2 使用條件

- **刊登租金與成交租金永遠分開統計、分開顯示**，不可合併成一個數字。
- 介面必須標示「刊登租金（廣告開價）」，不得描述為實際成交價格（US-06）。
- 同一物件可能重複刊登、改價後重新刊登，需要去重（見 [methodology.md §4](methodology.md#4-資料清理)）。
- 授權未確認前，**只能用於內部分析，不得提供下載**（US-10）。

### 5.1 已知限制

- **只有臺北市。** 其他縣市沒有紀錄，**不代表沒有違建**。介面必須明確顯示「此縣市沒有違建資料」，與「查無紀錄」區分（見 [architecture.md §7.3](architecture.md#73-資料覆蓋不均)）。
- 紀錄可能已拆除或已改善，需確認資料是否含處理狀態與日期。
- 涉及可辨識的地址，發布方式需經法律檢視（見 [architecture.md §7.2](architecture.md#72-回報審核與個資)）。

## 8. 新增來源的檢查清單

新增任何來源前，請開一個 GitHub Issue，並在本文件補上以下資訊：

- [ ] 提供者與網址
- [ ] 租金類型：刊登／成交／其他（非租金資料也要註明）
- [ ] **授權條款**，以及是否允許再發布與下載
- [ ] 涵蓋範圍（縣市、時間）
- [ ] 更新頻率，以及過期判定標準
- [ ] 欄位清單與預計用途
- [ ] 已知偏誤與限制
- [ ] 是否含個人資料；若有，如何排除
- [ ] 下載一份樣本檔，確認格式與本文件描述一致

3. 開放台灣民間租屋資料是否仍在更新？授權條款為何？
4. 臺北市違建資料是否公開、是否含地址與處理狀態？
5. MVP 1 是否只用實價登錄，刊登資料留到之後？（建議：是。先把一個來源做對。）
