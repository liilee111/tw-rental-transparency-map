# 台灣租屋透明地圖
### Taiwan Rental Transparency Map

讓租屋市場資訊更透明，幫助租屋者了解台灣各地的租屋行情。

## 專案介紹

台灣租屋透明地圖是一個開源公民科技專案，希望透過資料整理與視覺化，讓租屋者更容易了解不同縣市的租屋市場資訊。(**文件及系統架構會陸續規劃及上傳**)

## 開發目標

- 提供縣市租屋資訊搜尋。
- 呈現租屋市場統計數據。
- 公開資料來源、更新時間與統計方法。
- 提升租屋市場資訊透明度。

## 開發進度

目前開發階段：規劃中

| 階段 | 目標 |
|---|---|
| MVP 1 | 縣市搜尋與基本租屋市場統計 |
| MVP 2 | 行政區資訊與租金分布 |
| MVP 3 | 租金趨勢與區域比較 |

## 注意事項

本專案仍在早期開發階段，功能與資料來源可能持續調整。

**刊登租金不等於實際成交租金。** 本專案會盡可能清楚標示資料來源與限制，避免誤解租金資訊。
